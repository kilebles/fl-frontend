# fl-frontend

Web UI for [fl-api](https://github.com/kilebles/fl-api): batch video/image generation in Google Flow (Veo).

```bash
npm install
cp .env.example .env.local      # API URL
npm run dev                     # http://localhost:3000
```

The API must be running: `uv run python scripts/serve.py` in `../fl-api`.
